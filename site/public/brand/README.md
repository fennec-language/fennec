# Fennec's brand files

The mark is Scout's head: Fennec's fennec fox, drawn on a 100-unit grid. The SVGs are the masters; every PNG and the ICO are rendered from them.

| File | Use |
|---|---|
| `fennec-mark.svg` | The mark in colour. |
| `fennec-mark-mono-dark.svg`, `fennec-mark-mono-light.svg` | The mark in one colour, for light and for dark grounds, and for one-colour print. |
| `favicon.svg`, `favicon.ico`, `favicon-32.png` | The 16 px cut: drawn for the pixel grid, not scaled down. |
| `favicon-mono.svg` | The 16 px cut in one colour. |
| `fennec-app-icon.svg`, `icon-192.png`, `icon-512.png` | The app icon: the fox in negative space on an orange squircle. Also the avatar and social square. |
| `fennec-app-icon-square.svg`, `apple-touch-icon.png` | The app icon, full bleed, for platforms that round the corners themselves. |
| `fennec-wordmark.svg`, `fennec-wordmark-light.svg` | "fennec" in rounded monoline strokes, whose two n's peak like ears. |
| `fennec-lockup.svg`, `fennec-lockup-light.svg`, `fennec-lockup-1200.png` | The mark and the wordmark together. |
| `fennec-logo-512.png`, `fennec-logo-1024.png` | The mark as PNG, for places that can't take SVG. |
| `og-image.png` | The link preview: the lockup beside Scout at night. |
| `scout/` | Scout, the mascot: the base, the Explorer (his default), a one-colour print, six outfits, three docs moments, the 404 scene, the front page's night scene and a plush reference. |

## Rules

- Keep the mark's clear space at least the width of one ear tip on every side.
- Don't redraw, stretch, outline or recolour the mark beyond the one-colour files.
- Below 32 px, use the favicon cut, not the full mark.
- Scout wears one outfit at a time, matched to the page: Explorer for the tour and the docs, Racer for speed, Courier for kits, Detective for errors, Inspector for checks, Director for replay, Conductor for concurrency.
- The Scout art is final raster art, made with an image model and then cleaned. Vector redraws of it would be the next step.
