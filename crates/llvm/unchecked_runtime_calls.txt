# Runtime calls emitted code doesn't check yet, held to a ratchet by
# crates/llvm/src/failure_checks.rs: every runtime function not in fennec_runtime::NEVER_FAIL can
# fail, so a call to one needs the failure flag read after it. Each line is a runtime function, how
# it goes unchecked (`unchecked`: a way on from the call doesn't read the flag; `in-cant-fail`: the
# function it's in was emitted as unable to fail, so nothing checks there), and how many such calls
# the bench kernels make. A function not listed here mustn't go unchecked anywhere, and the
# kernels' counts must match: a fix lowers them, written with FENNEC_UPDATE_UNCHECKED=1.
#
# What a failed call hands back before anything reads the flag, from how emitted code declares
# each (2026-11-12). A failure gives back the type's default (`attempt`), so:
# - A block's address, 46 functions: null. Using it before the check reads address 0, undefined
#   in LLVM's terms. The finds (dict_find_by_value, dict_find_slice) are read as maybe-null
#   already; the rest aren't. Step 2's first PR makes each give back a safe block, or checks it.
#   alloc args_list block_text bytes_builder bytes_decode bytes_decode_problem bytes_grow
#   dict_add_new_slice dict_find_by_value dict_find_slice dict_new dict_set dict_set_header
#   float_text int_text list_extend list_grow list_new list_pop_unshare list_reserve list_slice
#   list_sorted list_sorted_by list_truncate list_unshare list_with_room not_a_number notes_shown
#   regex_problem set_clear str_append str_char_at str_codes str_concat str_encode str_from_code
#   str_from_code_problem str_join str_lower str_replace str_reversed str_strip str_upper
#   str_with_room text_block unshare
# - A plain value, 18 functions: zero. Wrong until the check, but nothing read through it.
#   args_len box_equal box_to_value clock_now dict_popped error_of list_contains notes_add
#   notes_frame notes_list parse_float parse_int regex_groups regex_is_valid str_compare str_find
#   text_contains unwrap
# - Nothing, 7 functions: constant_kept free input native_freed native_made trace_allocated, and
#   text_of, which writes a string's header through a pointer: what a failed one leaves there is
